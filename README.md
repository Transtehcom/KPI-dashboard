# Транстехком · тестовый дашборд на Rust

Приватная копия дашборда для проверки на учебных данных. Rust формирует страницы, рассчитывает показатели и обрабатывает действия. В браузере можно переключать профиль и месяц, открывать документы из показателей, менять решения по KPI и скачивать справочники в Excel.

## Локальный запуск

Из корня проекта с установленными Rust и Cargo выполните:

```powershell
cargo run --release --locked --bin ttk-preview -- --assets dist --store ./.local-sandbox --port 18765
```

Откройте [дашборд на этом компьютере](http://127.0.0.1:18765). Сервер привязан к loopback. Каталог `.local-sandbox` хранит учебные сеансы и позволяет продолжить работу после перезапуска.

## Сборка и проверка

Для сборки версии Sites нужны цель Rust `wasm32-unknown-unknown`, Node.js и npm.

```powershell
cargo test --locked
rustup target add wasm32-unknown-unknown
npm ci --ignore-scripts
npm run build:worker
npm run test:worker
npm run test:workerd
```

В Sites обработчики выполняются в Cloudflare Worker. Состояние сеанса хранится в D1. Основная логика едина для нативного сервера и Worker. Старые изменения из браузерного localStorage остаются только в том браузере. Новый серверный сеанс начинается с учебных данных.

Сверка с оригиналом воспроизводит записанные HTTP-запросы с помощью rust-anything и отдельно сравнивает содержимое книг Excel. [Команды проверки](verification/http/README.md) · [Карта переноса](rust/MAP.md).

## Что можно проверить

В копии доступны учебные профили и разделы с реестрами за 2026 год. Справочники перевозчиков и поставщиков, их выгрузки и решения по записям KPI доступны также через HTTP. Переключатель профилей моделирует права сотрудников внутри отдельного тестового сеанса.

Подключение рабочих баз 1С и Битрикс24, производственный вход, фоновая синхронизация, распознавание новых звонков, вызовы модели ttkGPT и внешняя отправка сообщений остаются отдельными задачами переноса.
