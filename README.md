# Транстехком · Дашборд на Rust

Интерактивная тестовая версия для Sites. Расчёты, представления, действия пользователя и формирование Excel находятся в Rust. Тонкий браузерный адаптер загружает WebAssembly, передаёт события, работает с файлами и хранит изменения в браузере.

## Сборка

Требуются Rust, Cargo и цель `wasm32-unknown-unknown`.

```powershell
cargo test --locked
cargo build --locked --lib --release --target wasm32-unknown-unknown
Copy-Item target/wasm32-unknown-unknown/release/ttk_dashboard_site.wasm dist/dashboard.wasm -Force
```

Для просмотра отдайте каталог `dist` по HTTP. Публичной точкой входа служит `index.html`. Копия Sites приватная, её конфигурация находится в `.openai/hosting.json`.

## Данные и границы переноса

Реестры генерируются локально за месяцы 2026 года. В шапке можно выбрать учебный профиль или месяц. Решения по KPI, настройки доступа и обращения с вложениями сохраняются в локальном хранилище текущего браузера. Переключатель профилей предназначен для проверки экранов и прав на учебных записях.

Рабочие подключения к 1С и Битрикс24, серверные учётные записи, периодическая синхронизация, распознавание новых записей и вызов модели ttkGPT относятся к отдельным серверным интеграциям. Чат в этой версии отвечает по локальным реестрам.

Для проверки совпадения поведения с исходным дашбордом используется [rust-anything](https://github.com/erkamyaman/rust-anything/tree/d1f3255e224134eb83c26a90a5478e732c5bc5ef). Браузерные проверки, тесты отдельных правил и сравнение с оригиналом учитываются раздельно.
