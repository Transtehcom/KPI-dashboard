# Постоянные сессии ttkGPT

Одна сессия Codex на чат. Мастер-инструкция сохраняется в локальный файл и подключается при создании через model_instructions_file. Это обходит ограничение длины командной строки Windows. Продолжение только по сохранённому точному UUID, без --last. Модель, мышление, Fast, месяц и дата могут меняться без потери истории.

1. Добавить поддержку session в транспорт Codex и хранение привязки chat/thread с отпечатком мастер-инструкции и прав.
2. Отправлять новые сообщения и отдельные результаты инструментов. Проверку тематики сотрудников вести в той же сессии отдельным режимом, серверные запреты сохранить.
3. Для старых чатов создать сессию с ограниченной сохранённой историей. При сбое/отмене инвалидировать неопределённое продолжение. Чистые сессии переживают перезапуск.
4. Проверить изоляцию двух чатов, смену прав, восстановление после сбоя, маскирование, продолжение инструментов и реальную память Codex. Полный прогон, локальный коммит, обновление процесса.

Состояние busy/active_message предотвращает повторное использование незавершённого контекста после сбоя. Не повторять автоматически неопределённый вызов, чтобы не дублировать правки документов.
