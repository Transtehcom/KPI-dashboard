# Документы во вкладке GPT

Поддержать загрузку и чтение DOCX, XLSX, TXT/MD/CSV и текстовых PDF. Для первых трёх групп выдавать изменённую копию. Хранение локальное в SQLite с привязкой к владельцу чата. Документы из согласованного списка обезличивать до передачи модели.

## Выполнение

1. Добавить таблицу вложений и модуль загрузки, извлечения текста и адресных правок. Проверить лимиты ZIP, типов и объёма, PDF без текстового слоя, сохранение оригинала и форматирования DOCX/XLSX.
2. Добавить инструменты document_list/read/edit в GPT. Проверить изоляцию чатов, обезличивание и обратное восстановление только новых фрагментов.
3. Подключить административные API загрузки и скачивания с проверкой владельца и лимитом тела запроса. В UI добавить выбор файлов, список версий и скачивание.
4. Проверить обычные точки входа, полный набор тестов и сквозной запрос к Codex. Сделать локальный коммит и обновить процесс.

## Проверки риска

Чужой чат, повреждённый/раздутый архив, PDF без текста, изменение оригинала, несовпадающий старый текст и потеря форматирования, утечка реквизитов в контекст. Не исполнять инструкции документов как системные команды.
