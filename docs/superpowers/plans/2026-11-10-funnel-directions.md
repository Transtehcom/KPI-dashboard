# Направления лидов и сделок в Воронках

> Выполнение по шагам через superpowers executing plans.

## Согласованное поведение

Фильтр действует в обеих подвкладках Воронок — По дате и Факт — внутри их существующих воронок и этапов. Направления EPC, БПЛА, KPI, Инвестиции, Факторинг берутся из полей Теги карточек Б24. Несколько выбранных направлений объединяются, карточка учитывается один раз. БПЛА совпадает по тегу либо по упоминанию в названии. Если одновременно выбраны KPI и БПЛА, включая дополнительные направления, используются только теги. «Все» показывает карточки без отбора по направлениям, включая карточки без тегов и с посторонними тегами. «Все с тегом» означает хотя бы один из пяти тегов направлений. Остальные фильтры периода, отдела, сотрудника и воронки продолжают действовать. КП исключены из текущей задачи.

## Реализация

- [x] Найти поля Теги по метаданным Б24, сохранить нормализованные теги в crm_deals и fact_records. Обновлять теги сохранённых исторических карточек, включая записи за пределами окна новых переходов.
- [x] Добавить общий отбор направлений перед расчётом счётчиков, сумм и расшифровок. Сохранить поведение существующих внутренних вызовов без нового аргумента.
- [x] Передавать выбор в API обеих подвкладок. Добавить выбор нескольких направлений, Все, пояснение текущего правила и параметры печати.
- [x] Проверить объединение, особое правило KPI и БПЛА, написания EPC и ЕРС, закрытые карточки Факта, обновление старых записей и отклонение неверных параметров.
- [x] Загрузить теги из Б24 только чтением, применить обновление атомарно и проверить рабочие отчёты. После итоговой проверки сохранить локальный коммит; предложить отправку в GitHub.

## Проверка и запуск

625 тестов прошли. Дополнительно проверены сохранение вариантов сотрудника/отдела/воронки при смене направления и теги демонстрационных карточек. Рабочие таблицы обновлены атомарно: 447 текущих карточек и 2634 исторических. Б24 вернул Not found для 11 старых лидов; их неизвестные теги не подменялись. Сервис перезапущен, главная страница отвечает HTTP 200, API без входа — HTTP 401.

После разделения «Все» и «Все с тегом» прошли 45 целевых проверок: расчёт лидов/сделок в обоих режимах, запросы API, переключение вариантов и подписи в печатном отчёте.

## Границы

Звонки и календарь на странице относятся к выбранным сотрудникам. Новый фильтр отбирает лиды и сделки. Теги исторического Факта описывают текущее поле карточки, поскольку история изменения тегов источником не предоставлена. Удалённая историческая карточка с неизвестными тегами не получает вымышленное направление.
