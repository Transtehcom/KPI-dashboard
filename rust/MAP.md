# Карта переноса веб-дашборда

Рабочий сайт и установочные приложения находятся вне этой копии. Исходники на Rust и собранный для Sites WebAssembly лежат в собственном репозитории.

## Что обследовано

Инструмент `rust-anything 3.3.0 analyze --whole-app` исследовал очищенную копию исходников. Он обработал 88 файлов Python (21 967 строк) и 6 модулей JavaScript (5 164 строки), включая клиентский код из HTML. Отдельный поиск в исходниках сервера выявил 70 различных буквальных путей `/api`. Эти числа описывают охват обследования.

## Статус по областям

| Область | Что доступно в копии | Что требует отдельной сверки или переноса |
| --- | --- | --- |
| Главное меню, права, темы | Тестовые профили, редактор видимости отделов, маршруты, статистика | Реальная аутентификация, серверная авторизация и изоляция учётных записей |
| KPI и загрузка | Пять профилей, пересчёт по решениям, сроки и детализация до документов, сравнение периодов | Полное совпадение всех расчётов и отбора первичных записей |
| Воронки, метрики, финансы | Обе воронки, отчёты по отделам, сравнение цен, документы сумм и календаря | Сверка HTTP-контрактов, история стадий и регистры поступлений |
| Справочники, сотрудники | Поиск, справочники, редактирование тестовых прав, экспорт XLSX | Обновление из рабочих источников и совместное хранение изменений |
| Звонки, ttkGPT, помощь | Подготовленные расшифровки, ответы по учебным реестрам, у обращения есть локальный получатель | Очередь распознавания, вызов модели, доставка во внешние каналы |
| Синхронизация и данные | Воспроизводимые учебные записи в браузере | Чтение 1С/OData и Битрикс24, хранение истории в SQL, фоновые задания |

## Проверки

Сборка проходит нативные тесты Rust. Браузерные сценарии отдельно проверяют маршруты, права тестовых профилей, изменение данных и экспорт. Сверка с исходным Python проводится на синтетических входах. Для всего исходного сервера `app replay` и итоговый `app lift` ещё не подтверждены.
