# Карта переноса веб-дашборда

В приватной копии можно пройти по всем разделам на учебных данных. Источник переноса — основной веб-дашборд. Установочные приложения находятся в отдельном проектном контуре.

## Обследование

`rust-anything 3.3.0 analyze --whole-app` обработал 88 файлов Python и 6 модулей JavaScript очищенного исходника. Отдельный поиск выявил 70 различных буквальных путей `/api`. Это инвентаризация исходного сервера. Каждый сценарий совпадения поведения требует отдельной проверки.

| Область | Что можно проверить | Осталось перенести или сверить |
| --- | --- | --- |
| Вход и хранение | Сеансы в локальном сервере и Sites, изоляция пользователей, учебные роли, защита от перезаписи устаревшим запросом | Вход по рабочим учётным записям, реальные назначения ролей |
| KPI и загрузка | Пересчёт решений и исключений, сроки и детализация по учебным документам, сравнение периодов | Первичные записи по всем сотрудникам и сверка всех формул |
| Воронки, метрики, финансы | Воронки, отчёты по отделам, сравнение цен, документы сумм и календаря | История стадий, рабочие регистры поступлений, сверка отчётных HTTP-методов |
| Справочники | HTTP для перевозчиков и базы поставщиков, права доступа и выгрузка XLSX | Получение актуальных записей из 1С |
| Звонки, ttkGPT, помощь | Учебные расшифровки, ответы по реестрам, тестовые обращения с вложениями | Очередь распознавания, вызов модели и доставка во внешние каналы |
| Синхронизация | Серверное хранение учебных изменений | Чтение 1С/OData и Битрикс24, фоновые задания и история синхронизаций |

## Проверки

Нативная сборка и Worker используют один Rust-обработчик. Тесты браузера проверяют переходы и действия в интерфейсе. Для сверки исходного сервера rust-anything записывает HTTP-ответы оригинала на синтетических данных и повторяет запросы к Rust. Для XLSX сравниваются книги после распаковки. Полная эквивалентность исходного сервера пока не подтверждена. [Корпус запросов и инструкция](../verification/http/README.md).
