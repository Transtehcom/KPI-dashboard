# Сверка HTTP-обработчиков с исходным дашбордом

Для запуска нужны Git, Python 3.11 или новее с openpyxl, rust-anything 3.3.0 и нативная сборка `ttk-preview`. Запускать из корня Rust-копии.

```powershell
cargo build --release --locked --bin ttk-preview
python verification/http/verify.py --reference C:/path/to/original-dashboard --tool C:/path/to/rust-anything.exe --rust-server target/release/ttk-preview.exe
```

Оригинальный checkout должен содержать коммит `7d2da43eb827317cb86f99482ee2e7c79f95ed40`. Скрипт извлекает из него Python-модули, статические JSON-словари каталога `app` и регламент `kpi_rules.json` в новую временную папку. Исходный HTTP-обработчик обращается к SQLite в памяти. Оба процесса слушают loopback. Python-аудит блокирует исходящие подключения, запуск подпроцессов из HTTP-обработчика и открытие файловой базы.

Исходная база и Rust используют один синтетический набор поставщиков и поручений. Запросы проверяют видимость справочников для трёх профилей, отсутствие сессии, поиск, а также запись, сброс и валидацию согласований и исключений по поручениям KPI 5 и недельной оценке KPI 4 логиста. `rust-anything app record` дважды запускает оригинал. Затем `app replay` сопоставляет статусы, заголовки и JSON двух реализаций на одних и тех же запросах. Применяется нормализация порядка ключей объектов JSON. Записи с нестабильным ответом завершают проверку ошибкой.

У XLSX меняются служебные метки времени внутри ZIP. Для шести выгрузок проверяются имя файла, названия и размеры листов, значения и типы непустых ячеек, фильтры и закреплённые области. Набор включает полную, частичную и пустую выдачу для обоих справочников.

Отдельная проверка API песочницы создаёт два сеанса Rust-сервера, меняет тему в первом и перезапускает процесс с тем же хранилищем. Она проверяет сохранение темы, разделение сеансов, обработку устаревшей ревизии и форму ответа браузеру.

Раннер печатает путь к лаборатории с `record.json`, `original-replay.json`, `rust-replay.json`, `workbooks.json`, `session-check.json` и сохранёнными запросами. Параметр `--output` задаёт родительский каталог. Для сравнения очередной сборки с готовой записью передайте `--lab` вместо `--reference`.
